Strict Data Privacy

Strict User & Data Isolation

Enterprise security with zero data leakage. Your personal schedule, emails, and conversations are never shared with other team members or workspaces.

How it works for you: When User A asks about their calendar in a public channel, the AI only reads User A's calendar. User B cannot access User A's data, and each tenant operates in a walled database partition.
🔒 Privacy Guarantees
  • Per-user Google OAuth credentials strictly linked to your Slack User ID
  • Encrypted PostgreSQL storage with tenant-isolated database keys
  • Zero cross-workspace data access or public workspace directory leaks
  • Your conversations and emails are never used to train public AI models

Quick-Start Guide

How to Talk to the Bot in Slack

Interacting with your AI assistant is seamless and takes zero training. Use it across your daily workflow in 3 simple ways:

1. In Any Channel: Type /invite @myagent to bring the bot into any channel. Mention @myagent with your question and it will respond directly in thread or channel.
2. In Private Direct Messages: Send a 1-on-1 DM to the bot anytime for private calendar checks, email searches, and confidential task assistance.
💬 Thread Interactions
3. Inside Message Threads: Mention @myagent inside any ongoing thread. The bot automatically digests previous replies in the thread to give context-aware responses without spamming the main channel.
